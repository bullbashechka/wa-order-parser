# wa-order-parser

Приложение принимает корзины (заказы) из WhatsApp Business, пишет их в дневные
CSV-журналы и формирует рабочие документы развозки: экспедиционный лист и накладные
на отпуск товара (XLSX). Подробная спецификация — в `../PRD.md`.

## Требования

- Node.js 18+ (используются `fs/promises`, `Intl` с таймзонами).

## Установка

Из корня репозитория:

```bash
npm install          # ставит зависимости приложения (postinstall → app/)
```

или прямо в папке приложения:

```bash
npm --prefix app install
```

## Настройка

1. Скопируйте `app/.env.example` в `app/.env` и при необходимости поправьте значения.
   Все относительные пути считаются от папки `app/`.

   | Параметр | По умолчанию | Назначение |
   |---|---|---|
   | `TIMEZONE` | `Asia/Almaty` | таймзона для дат и группировки по дню |
   | `CSV_DELIMITER` | `;` | разделитель CSV (Excel-локаль RU/EU) |
   | `OUTPUT_DIR` | `data/days` | корень папок дня |
   | `PROCESSED_MESSAGES_PATH` | `data/processed-messages.json` | защита от дублей |
   | `CLIENTS_PATH` | `clients.json` | справочник «телефон → имя» |
   | `GENERATE_TIME` | `06:00` | время ежедневной генерации |
   | `COMPANY_NAME` | `Моя организация` | «Исполнитель» в накладной |
   | `INVOICE_CURRENCY` | `KZT` | валюта накладной (всегда тенге) |
   | `DEFAULT_UNIT` | `упак` | единица измерения в накладной |
   | `WWEBJS_AUTH_PATH` | `../.wwebjs_auth` | папка сессии WhatsApp |

2. Заполните `app/clients.json` — соответствие номера телефона имени клиента:

   ```json
   { "77001234567": "ИП Иванов", "77019876543": "ТОО Ромашка" }
   ```

## Первый запуск и QR-код

```bash
npm start            # фоновый режим: приём заказов + планировщик
```

При первом запуске в терминале появится QR-код — отсканируйте его в WhatsApp на
телефоне (раздел «Связанные устройства»). Сессия сохранится в `.wwebjs_auth`, и при
повторных запусках QR больше не понадобится, пока сессия валидна.

## Где искать результаты

```
app/data/days/YYYY-MM-DD/
  orders.csv          # сырые строки заказов за день (по строке на товар)
  expedition.xlsx     # экспедиционный лист (сборка за день)
  invoices/
    Заказ №N от DD.MM.YYYY — <Клиент>.xlsx
```

## Генерация документов

Документы формируются **по расписанию** за предыдущий день (в `GENERATE_TIME`).
Сформировать вручную за конкретную дату:

```bash
npm run build-day -- 2026-06-25
```

Команда читает `orders.csv` указанного дня и детерминированно (пере)создаёт
`expedition.xlsx` и накладные.

## Фоновый запуск через pm2

```bash

```

## Предупреждение

`whatsapp-web.js` — **неофициальная** библиотека, не аффилированная с WhatsApp.
Приложение рассчитано на низкий объём сообщений и не предназначено для массовых
рассылок или высоконагруженного продакшена.
